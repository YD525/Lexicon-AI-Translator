# Contributing to SSELexicon

Thank you for your interest in contributing!

## 🛠️ How to Contribute

- Fork this repository
- Clone your fork
- Create a new branch
- Make your changes
- Submit a Pull Request (PR)

## 📦 Build Requirements

- Visual Studio 2022+
- .NET 8.0 SDK
- Windows OS

## 🔍 Review & Acceptance Policy

By submitting a Pull Request, you acknowledge and agree that:

- All contributions will be **reviewed and evaluated by YD525**
- Acceptance, modification, or rejection of submissions is based on **code quality, design consistency, performance, maintainability, and project direction**
- The maintainer reserves the right to **request changes, refactor, partially adopt, or decline** any contribution

Submission of a Pull Request does **not** guarantee inclusion in the project.
