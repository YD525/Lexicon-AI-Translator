# Contributing to SSELexicon

Thank you for your interest in contributing!

## 🛠️ How to Contribute

- Fork this repository
- Clone your fork
- Create a new branch
- Make your changes
- Submit a Pull Request (PR)

## 📦 Build Requirements

- Visual Studio 2022+
- .NET 8.0 SDK
- Windows OS

## 🔍 Review & Acceptance Policy

By submitting a Pull Request, you acknowledge and agree that:

- All contributions will be **reviewed and evaluated by YD525**
- Acceptance, modification, or rejection of submissions is based on **code quality, design consistency, performance, maintainability, and project direction**
- The maintainer reserves the right to **request changes, refactor, partially adopt, or decline** any contribution

Submission of a Pull Request does **not** guarantee inclusion in the project.

## 💬 Questions?

## ✍️ Authorship & Rights

If you contribute code to SSELexicon or any related component, you will be recognized as an author of your contributed code.
You are free to use, modify, and reuse **your own contributions** in any form or project of your choice, provided that such use does not violate the licenses of this repository or its dependencies.
If your contribution is substantial, you will be recognized as one of the authors of SSELex and may be granted additional rights accordingly.
