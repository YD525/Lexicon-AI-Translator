# Workflow wireframes

The [workflow board](workflow-board.svg) covers all eight target workflows at low fidelity. Each frame preserves
the same shell regions: project identity and global status at the top, workflow navigation on the left, primary
content in the center, optional context on the right, and operation feedback at the bottom.

The frames establish hierarchy and action placement only. Color, typography, detailed spacing, icons, and final
copy are intentionally excluded from the low-fidelity artifact.

| Frame | Primary user outcome |
|---|---|
| Open | Choose or drop a project and understand loading, warning, or failure state. |
| Translate | Work through a filtered entry list with source, target, context, and operation progress. |
| Review | Compare provenance and context, then record a durable review decision. |
| Quality | Run checks, filter findings, and navigate directly to affected entries. |
| Export | Understand readiness, select format and destination, and validate the result. |
| History | Compare revisions and restore without destroying provenance. |
| Update | Compare project revisions, resolve ambiguous matches, and apply safely. |
| Settings | Edit staged intent-based settings with explicit Apply and Cancel. |
