# Brand-aligned visual direction

The three high-fidelity direction boards apply the proposed tokens to the approved information architecture:

- [Shell](shell.svg): stable project identity, navigation, global status, and empty project state.
- [Translation workspace](workspace.svg): compact entry list, source and target editor, context inspector, and
  visible operation state.
- [Settings](settings.svg): intent-based navigation, staged cards, inline validation, and persistent Apply or
  Cancel actions.

These are implementation references, not pixel contracts. Text may change under stable message identifiers,
and detailed control behavior follows the state catalogue. The selected direction preserves the existing gold
identity accent and charcoal surfaces while using blue consistently for focus and information.
